# PediCafe
Sistema web de pedidos para cafetería. Proyecto del grupo 7
PediCafé

Descripción

PediCafé es una aplicación web para una cafetería que permitirá consultar el menú, personalizar productos, realizar pedidos y seleccionar una hora de retiro. El personal podrá gestionar la preparación y entrega, mientras que la administración controlará productos, inventario, usuarios y ventas.

Funcionalidades previstas

Consulta del menú por categorías.

Registro e inicio de sesión con roles.

Carrito de compras y personalización de productos.

Confirmación de pedidos y selección de hora de retiro.

Pago simulado con tarjeta o pago en caja.

Seguimiento del estado del pedido.

Gestión de pedidos para barra y caja.

Administración de productos, categorías e inventario.

Gestión de colaboradores y reportes básicos de ventas.


Tecnologías previstas

Java y Spring Boot para el backend.

Bootstrap para la interfaz.

Base de datos relacional.

GitHub para el control de versiones.


Acuerdo básico de trabajo por ramas
